# Lamofel form examples

Four plain HTML forms you can copy: contact, waitlist, feedback and RSVP. They match the four form generators listed at https://lamofel.com/tools.

Lamofel is a form backend for HTML forms and static sites: https://lamofel.com/?ref=github-examples

## How to use one

1. Pick a file: `contact.html`, `waitlist.html`, `feedback.html` or `rsvp.html`.
2. Copy the `<form>` block into your page.
3. Replace the placeholder action `https://lamofel.com/f/YOUR_FORM_ID` with your own endpoint, which you get by signing up at https://lamofel.com/?ref=github-examples.
4. Publish. No JavaScript is needed.

The field names and wording in these files are only suggestions. Rename, add or remove fields to suit your page.
