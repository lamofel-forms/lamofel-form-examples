# Lamofel form examples

Four plain HTML forms you can copy: contact, waitlist, feedback and event reply. They match the four form generators listed at https://lamofel.com/tools

Lamofel is a form backend for HTML forms and static sites: https://lamofel.com/?ref=github-examples

## How to use one

1. Pick a file: contact.html, waitlist.html, feedback.html or event-reply.html.
2. Copy the form block into your page.
3. Replace the placeholder action in the form with your own endpoint, which you get when you sign up at the Lamofel site above.
4. Publish. No JavaScript is needed.

The field names and wording in these files are only suggestions. Rename, add or remove fields to suit your page.
